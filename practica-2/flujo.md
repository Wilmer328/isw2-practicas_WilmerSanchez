\# GitFlow vs Trunk-Based



GitFlow es un modelo de trabajo que utiliza varias ramas, como main, develop y ramas para nuevas funciones, correcciones y versiones. Es útil para proyectos grandes donde se necesita un mayor control sobre el desarrollo.



Trunk-Based Development trabaja principalmente sobre una sola rama principal. Las ramas de trabajo son pequeñas y de corta duración, por lo que los cambios se integran rápidamente.



Para una aplicación web elegiría Trunk-Based porque facilita la integración continua, reduce los conflictos entre ramas y permite publicar nuevas funciones con mayor rapidez. También mejora la colaboración del equipo y mantiene el código siempre actualizado.
